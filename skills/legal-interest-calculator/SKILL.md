# 法律利息计算

模型负责理解材料、确定计息口径和最终复核；本地程序负责金额计算与稳定导出。运行环境为本机 Python 3.10 及以上，不依赖 API、付费服务或第三方 Python 包。

## 提取计息口径

先阅读用户明确提供或指定的当前材料。扫描件先做本地文字识别并核对关键页面；无法确认的文字不能直接成为参数。将每个债务的本金、起止日期、利率依据、年基准、首尾日、已确定冲减本金的还款、排除期间及来源位置整理成简短口径表。

详细规则见 [references/legal-rules.md](references/legal-rules.md)。特别注意：

- 区分约定利率、固定基准日 LPR、随公告变化的 LPR。不要仅因用户提到“利息”就选 LPR；不要仅因债务期限长就选五年期以上品种。
- 单利是本工具的计算范围。材料要求复利、按整月结息、银行专用重定价、自动分配费用和利息，或自动判断民间借贷保护上限时，先说明需要进一步确定参数，不要把它们悄悄改成现有规则。
- 一般债务利息与加倍部分分别输入；加倍部分的基数由材料确定，不能默认包含一般债务利息，不能默认等于所有一般本金相加。
- 收款总额与归还本金不等同。只有已确定冲减本金的金额才能写入 repayments。同一还款的多份证据不能重复录入。
- 签收日不当然等于文书生效日；履行期限、休假日顺延、分期履行、中止期间以及划拨、拍卖等截止节点需分别核对。
- 不自行填补关键口径。材料与用户指令已经明确时直接继续；只有影响结果且无法推定的缺项才询问用户。用户授权采用假设时在 analysis.assumptions 中记明。关键项未决时保存 draft，列出 unresolved，不能给确定金额。

## 生成参数并调用本地程序

首次使用时读取 [references/input-schema.md](references/input-schema.md)。按该格式保存独立的 UTF-8 参数文件，金额和利率使用十进制字符串；来源写到文件名与页码、条款或用户指令。不要修改原始材料。

analysis.status 为 ready 表示计息参数已齐备，不表示用户作出了程序中不存在的确认。不要伪造确认或法律依据。

将下列路径替换为本 skill 的实际目录和当前任务的输出目录；命令中的路径始终正确引用：

    python3 "<skill-dir>/scripts/calculate.py" --input "<task-dir>/plan.json" --output-dir "<task-dir>/outputs/run-01"

这条命令会完成严格参数校验、十进制分段计算、Word/Excel/HTML 导出、按日 Fraction 独立重算和最终导出内容核对。失败退出码为 2；出现错误时修复参数后重新运行，不能将旧结果当作本次结果。默认不覆盖既有输出。

需要单独复核已导出的包时：

    python3 "<skill-dir>/scripts/verify.py" --bundle "<task-dir>/outputs/run-01"

历史 LPR 数据来自官方公开接口，随结果保存当次快照。动态 LPR 截止日超过数据核验日期时程序会阻止计算。只有需要更新公开利率时才运行以下维护命令，计算本身不联网：

    python3 "<skill-dir>/scripts/update_lpr.py" --through "YYYY-MM-DD"

将日期替换为当前实际核验日期。更新失败时保留原快照，不改称“已更新”。2019-08-20 以前的利率应根据案件依据使用 fixed 或 schedule，不能套用改革后的 LPR。

## 模型最终复核

程序核验通过后，模型仍须：

1. 对照原始材料复核 source-plan.json 中的金额、日期、单位、LPR品种及动态或固定口径、还本分配、排除期间，检查遗漏或重复。
2. 阅读 interest-result.json 和 verification.json，确认独立重算及文件核验通过；抽查首段、利率变动日、还本日、末段和合计。
3. 检查最终 Word 与 Excel 内容和可读性；有渲染工具时查看最终导出文件的预览。只有结构和金额核验时，如实说明尚未完成视觉检查。
4. 将模型对材料口径的复核结论保存为 model-review.md，记明已核对的来源、采用的假设、抽查项与剩余问题。程序通过不能代替法律口径正确；没有做过的复核不得写成已完成。

交付 Word、Excel 与必要的口径说明，简洁告知一般债务利息、加倍部分、合计、截止日期和采用的关键规则。保留参数、结果、利率快照和核验记录以供复算。用户只要金额时可以仅导出 json，不强制交付其他格式。

当前版本不包含脱敏步骤。读取提供给模型的文件仍受所用客户端的数据处理政策约束；不要宣称原文件因使用本地计算就没有进入模型处理范围。不要向 GitHub、Issue 或外部服务上传实际案件材料。
